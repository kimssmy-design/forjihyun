사용법

  1. 아이 추가로 이름을 넣어요. 여러 명은 줄바꿈으로 한꺼번에 넣어요.
  2. 아이를 누르고 사진을 넣어요. 찍은 날짜순으로 자동 정렬돼요.
  3. 단체사진·행사 사진은 공통 사진에 넣으면 모든 아이 영상에 들어가요.
  4. 영상 만들기를 누르고, 완성되면 저장하거나 공유해요.

기기별 저장

  • 아이폰: [영상 저장] → '동영상 저장'을 누르면 사진 앱에 들어가요.
  • 갤럭시: 내 파일 → 다운로드 폴더에 저장돼요. 갤러리에서도 보여요.
  • PC: [남은 아이 모두 만들기]로 반 전체를 차례대로 만들 수 있어요. '여러 파일 다운로드' 허용 창이 뜨면 허용해 주세요.

알아 두면 좋아요

  • 카톡으로 받은 사진은 '원본'으로 저장해야 찍은 날짜가 남아요.
  • 영상 만드는 동안에는 화면을 켜 두고 다른 앱으로 넘어가지 마세요.
  • 사진은 서버에 올라가지 않고 이 기기에만 저장돼요. 아이폰은 이 페이지를 오래(7일 넘게) 안 열면 저장한 사진이 지워질 수 있으니, 며칠 안에 몰아서 만들어 주세요.
  • 카톡 안에서 열면 저장이 안 될 수 있어요. 크롬·삼성 인터넷·사파리로 열어 주세요.
